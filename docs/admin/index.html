ACCESSO

Per salvare le modifiche serve la tua chiave di accesso GitHub (token). Resta solo in questo browser: non viene inviata a nessun altro sito oltre a GitHub.

Avanzate
Come creo la chiave di accesso? (una volta sola)
  1. Apri github.com/settings/personal-access-tokens/new (entra con il tuo account).
  2. Token name: scrivi Pannello Kairos. Expiration: scegli la durata che preferisci.
  3. Repository access: scegli Only select repositories e seleziona kairos-store.
  4. Permissions → Repository permissions → Contents: scegli Read and write.
  5. Premi Generate token, copia la chiave e incollala qui sopra.
La chiave può modificare solo il repository kairos-store. Se la perdi o scade, ne crei un'altra allo stesso modo.
